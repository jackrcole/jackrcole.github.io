# jackrcole.github.io

Personal website and portfolio for **John (Jack) Cole**.

This site highlights my research, projects, and background in:
- multi-agent reinforcement learning
- autonomous systems
- embedded software engineering

## Tech stack

- [Astro](https://astro.build/)
- [Tailwind CSS](https://tailwindcss.com/)
- [DaisyUI](https://daisyui.com/)

## Local development

```bash
pnpm install
pnpm run dev
```

## Build for production

```bash
pnpm run build
pnpm run preview
```

## Site structure

- `/` — Home and featured work
- `/projects` — Research and applied projects
- `/cv` — Education, experience, publications, and skills

## Deployment

The site is deployed to **GitHub Pages** via `.github/workflows/deploy.yml`.
